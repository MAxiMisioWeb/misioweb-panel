# MisioWeb · Panel de proyecto

Panel para organizar la información de cada cliente web, dejar que el cliente elija widgets y generar la propuesta a partir de esa elección. Incluye un plugin de WordPress que muestra el avance en el sitio del cliente y lo sincroniza con el panel.

## Estructura

- `panel/prototipo/`: prototipo en un solo HTML (datos en localStorage, sin backend).
- `wp-plugin/misioweb-progreso/`: plugin de WordPress v0.1.0 (sin probar en un WordPress real).
- `docs/spec.md`: modelo de datos, endpoints y reglas de cálculo.
- `CLAUDE.md`: contexto y decisiones para trabajar con Claude Code.

## Cómo trabajar

Abrir el repositorio en claude.ai/code y pedir tareas siguiendo el orden de `CLAUDE.md`. No subir tokens ni claves al repositorio.
